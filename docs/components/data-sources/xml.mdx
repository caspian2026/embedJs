---
title: '🧾 XML'
---

You can load any XML file from your local file system or through a URL.
Headers are included for each line, so if you have an `age` column, `18` will be added as `age: 18`.

## Install XML addon

```bash
npm install @caspian2026/embedjs-loader-xml
```

## Usage

### Load from a local file

```ts
import { RAGApplicationBuilder } from '@caspian2026/embedjs';
import { OpenAiEmbeddings } from '@caspian2026/embedjs-openai';
import { HNSWDb } from '@caspian2026/embedjs-hnswlib';
import { XmlLoader } from '@caspian2026/embedjs-loader-csv';

const app = await new RAGApplicationBuilder()
.setModel(SIMPLE_MODELS.OPENAI_GPT4_O)
.setEmbeddingModel(new OpenAiEmbeddings())
.setVectorDatabase(new HNSWDb())
.build();

app.addLoader(new XmlLoader({ filePathOrUrl: '/path/to/file.xml' }))
```

### Load from URL

```ts
import { RAGApplicationBuilder } from '@caspian2026/embedjs';
import { OpenAiEmbeddings } from '@caspian2026/embedjs-openai';
import { HNSWDb } from '@caspian2026/embedjs-hnswlib';
import { XmlLoader } from '@caspian2026/embedjs-loader-csv';

const app = await new RAGApplicationBuilder()
.setModel(SIMPLE_MODELS.OPENAI_GPT4_O)
.setEmbeddingModel(new OpenAiEmbeddings())
.setVectorDatabase(new HNSWDb())
.build();

app.addLoader(new XmlLoader({ filePathOrUrl: 'https://www.w3schools.com/xml/plant_catalog.xml' }))
```
